⚠ Finding — Luware & D365 Channel Integration Framework (verified Jun 2026)
  • Luware Nimbus does not support D365 CIF v1 or v2. It ships no Channel Integration Framework channel provider / softphone widget for model‑driven apps. Per Luware's own integration docs: “Luware does not offer its own widget … Calls must be answered via MS Teams. It always rings in MS Teams.”
  • Nimbus is a native Microsoft Teams app — Teams is the call client. D365 integration is achieved via Conversation Context (screen‑pop of a D365 URL in the browser), the Power Automate connector (event triggers → create/update Dataverse activities/cases), an embedded web app in Nimbus dashboards, the OData API (reporting), and click‑to‑call links.

🔔 Where does an inbound call ring? — Teams and D365 (same line)
  • The dialer is not a separate phone system — it surfaces the seller's own Teams Phone number/identity inside D365. So a PSTN call rings in the Teams app (desktop/mobile) and pops a notification in D365 at the same time; the seller answers in either surface.
  • Answering in Teams desktop is valid and is not logged as missed — but auto‑logged activity, screen‑pop & Conversation Intelligence only fire when answered inside D365.
  • Two admin toggles govern it: Answer incoming calls in Dynamics 365 (OFF = D365 outbound‑only, rings only in Teams) and Internal call rings only in Teams (default ON → internal Teams‑to‑Teams calls ring only in Teams; external/PSTN ring in D365).
↪️ Advisor busy → redirect to the sales assistant — without Contact Center
  • No Omnichannel/ACD routing engine is needed: this is native Teams Phone call handling on the advisor's own line.
  • Recommended: the advisor's unanswered/busy rule redirects the inbound PSTN call to the sales assistant after a timeout. Busy only follows the redirect when Busy‑on‑busy = Use unanswered settings (otherwise a busy advisor returns a busy tone).
    Set-CsTeamsCallingPolicy -Identity Global -BusyOnBusyEnabledType UseUnanswered
    Set-CsUserCallingSettings -Identity advisor@… -IsUnansweredEnabled $true `
      -UnansweredDelay 00:00:20 -UnansweredTargetType SingleTarget `
      -UnansweredTarget assistant@…
  • Alternatives (still plain Teams Phone): a call group / delegation (assistant as backup answerer), or a lightweight Teams Call Queue / Auto Attendant on a free resource account that rings the advisor then overflow/timeout‑routes to the assistant.
  • Upgrade path: naturally graduates to Dynamics 365 Contact Center later for skills‑based queues, SLAs & supervisor dashboards — no rework of the underlying Teams Phone line.

Consent & mid‑call revocation — does the transcript still work?

Real‑time extraction works in Option B — but it is gated by consent. The transcript only streams while transcription is active, so the design must capture consent up front and stop instantly if it is withdrawn.

  • Full Transcription + recording when audio is also permitted
  • Consent state is preserved across transfers & escalations
✗ Consent declined
  • No transcript generated; reps can't start, pause or access it
  • AI features degrade gracefully → manual workflow (not a hard dependency)
  • Preference carried through if escalated to a human rep
⏸ Customer withdraws consent mid‑call — fully supported, and it is the technical "fix":
Agent / automation triggers→ pauseTranscription() + pauseRecording() (API GA Jun 2025)→ ACS stops emitting TranscriptionData→ extraction halts automatically→ flag consent=withdrawn · stop/redact downstream AI
Optional: auto pause/resume on hold · ACS PII redaction (preview) as defense‑in‑depth.

Legal impact — Switzerland (all‑party consent)

Art. 179bis / 179ter Swiss Criminal Code

Recording a non‑public conversation without all parties' consent is a criminal offence. Live transcription captures conversation content → it counts.

revFADP/nDSG + FINMA

Personal‑data processing under the revised Data Protection Act (in force Sep 2023) plus FINMA outsourcing/data‑location expectations. Residency handled by CH geo.

Must‑have design controls

Announce + capture consent before transcript · honor decline & mid‑call revocation instantly · log consent state · keep data in CH geo + retention/deletion (RMS).

Graceful degradation = compliant

AI prefill, NBA & summaries are enhancements, not dependencies. The no‑consent path must run as a full manual workflow.
