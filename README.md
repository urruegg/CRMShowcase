## Repository guidance

GitHub Copilot instructions for this repository live in
[`.github/copilot-instructions.md`](.github/copilot-instructions.md).
Guidance is organized by domain:

- **Architecture domains** (`docs/domains/architecture/`) — CRM core
  platform and other systems/integrations.
- **Functional domains** (`docs/domains/functional/`) — Sales, Customer
  Service, Marketing, Field Service.

See [`docs/domains/README.md`](docs/domains/README.md) for the full domain
map, and [`.github/agents/`](.github/agents/) for the custom Copilot agents
scoped to each domain.
