# Architecture Decision Records

An ADR captures **one architectural decision** and why it was made. One decision per file.

## Shape
Copy [ADR-0001-adopt-agent-driven-copilot-governance.md](./ADR-0001-adopt-agent-driven-copilot-governance.md)
and edit — do not invent a new shape.

## Naming
`ADR-####-kebab-case-title.md`, four-digit sequence, no gaps.

## When to open one
- Change to an agent tool schema.
- Change to a model, prompt, or eval baseline.
- Change to the data model.
- Change to the human/agent split in a workflow.
- Change to identity or network posture.

## When *not* to open one
- Local refactor, dependency bump, typo fix, docs polish. Use a normal PR.
